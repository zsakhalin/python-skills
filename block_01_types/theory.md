# Block 01 — Types & Data Structures

## Встроенные типы / Built-in types

### Числа / Numbers
- `int` — целое число: `42`, `-7`
- `float` — число с плавающей точкой: `3.14`, `-0.5`
- `bool` — булево значение: `True`, `False` (наследуется от int — True=1, False=0)

### Строки / Strings
- `str` — строка: `"hello"`, `'world'`
- Неизменяемые — нельзя изменить символ по индексу
- f-строки: `f"Hello, {name}"`

### None
- Означает отсутствие значения
- Не то же самое что `0` или `""`

|-----|-----------|----------------|----------------------|--------|----------|--------------------|

## Основные структуры данных / Data structures

### list — упорядоченный изменяемый список
```python
fruits = ["apple", "banana", "cherry"]
fruits.append("date")      # добавить в конец
fruits[0]                  # получить по индексу → "apple"
fruits[-1]                 # последний элемент → "date"
fruits[1:3]                # срез → ["banana", "cherry"]
```

### tuple — упорядоченный неизменяемый список
```python
point = (10, 20)
x, y = point               # распаковка
```
Используй когда данные не должны меняться — координаты, RGB цвет, константы.

### dict — пары ключ-значение
```python
user = {"name": "Sasha", "age": 25}
user["name"]               # → "Sasha"
user.get("email")          # → None (не KeyError)
user["city"] = "Moscow"    # добавить ключ
```

### set — неупорядоченное множество уникальных элементов
```python
tags = {"python", "backend", "python"}  # → {"python", "backend"}
tags.add("fastapi")
"python" in tags           # → True
```
Используй когда нужна уникальность или быстрая проверка `in`.

## Comprehensions

### List comprehension
```python
# Обычный способ
squares = []
for n in range(5):
    squares.append(n ** 2)

# Comprehension
squares = [n ** 2 for n in range(5)]  # → [0, 1, 4, 9, 16]

# С условием
evens = [n for n in range(10) if n % 2 == 0]  # → [0, 2, 4, 6, 8]
```

### Dict comprehension
```python
words = ["apple", "banana", "cherry"]
lengths = {word: len(word) for word in words}
# → {"apple": 5, "banana": 6, "cherry": 6}
```
